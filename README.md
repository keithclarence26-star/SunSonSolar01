# Project Title: SunSonSolar01

## System Description

SunSonSolar01 is a web application built with PHP and CodeIgniter 3. It features a solar energy themed home page and lets users create an account, log in, and log out. Account details are stored in a MySQL database, and passwords are hashed when accounts are created.

## How to Use the System

1. Open the system in your browser and view the home page.
2. Select **Create Account** or go to `/register` to register. Enter the required details and a valid, unused email address.
3. Go to **Log In** or `/login` and enter the email address and password you registered with.
4. Select **Log Out** when you want to end your 
session.
